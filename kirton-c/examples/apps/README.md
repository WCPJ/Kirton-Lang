# Прикладные примеры Kirton 1.1

Все блоки в примерах используют фигурный синтаксис Kirton 1.1. Синтаксис 1.0 с
`конец` по-прежнему принимается интерпретатором, но в новых программах
рекомендуются `{}`.

## Трекер задач

Из каталога `examples/apps` запустите:

```sh
kirton task_tracker.kir
```

Пример разделяет модель задач и программу на два файла. Он показывает приватные
структуру и enum внутри модуля, именованные конструкторы, изменение полей,
квалифицированный импорт, обход списка и перехват runtime-ошибки с блоком
`всегда`.

Ожидаемый вывод:

```text
Ошибка обработана: runtime
Обработка завершена
Открытых задач: 2
✓ Проверить память
· Сверить модули
· Подготовить релиз
TASK_TRACKER_OK
```

## Отчёт расходов

```sh
kirton expense_report.kir
```

Этот пример использует собственные структуры и enum для категорий и суммирует
расходы по категории в отдельном модуле. Успешный запуск печатает `EXPENSE_REPORT_OK`.
