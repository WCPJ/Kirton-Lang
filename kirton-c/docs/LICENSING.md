# Licensing Kirton Runtime and embedded applications

Kirton Core, interpreter, runtime, and public libraries are covered by the
Mozilla Public License 2.0 (MPL-2.0). Read the complete [`LICENSE`](../LICENSE)
before distributing Kirton or a product that embeds its runtime.

MPL-2.0 is file-level copyleft. Separate files that form a larger work may be
distributed under terms of your choice, including commercial/proprietary terms.
Writing an independent program in Kirton or running it with the interpreter
does not, by itself, make that program an MPL-covered Kirton file. The MPL does
not impose a blanket requirement to publish the source of separate user
applications.

When distributing the Kirton executable, static library, or another executable
that contains covered Kirton code, make the corresponding covered Kirton
Source Code Form available under MPL-2.0 and tell recipients how to obtain it.
If you modify MPL-covered Kirton files, those modifications to covered files
remain subject to MPL-2.0 when distributed. Preserve applicable license and
copyright notices. A static library does not remove these source and notice
obligations for the covered Kirton files incorporated into a distributed
executable.

This document is a practical summary, not legal advice. The full license text
controls. The third-party `stb_image` component remains under its own upstream
notice, as described in [`THIRD_PARTY_NOTICES.md`](../THIRD_PARTY_NOTICES.md).
