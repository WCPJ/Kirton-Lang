# Аудит времени жизни старых нативных модулей

Статус: **статический аудит завершён; process-exit cleanup добавлен; VM-scoped
ownership не реализован**.

## Выводы

| Модуль | Текущее владение | Очистка | Остаточное ограничение |
|---|---|---|---|
| `mod_bitmap` | Process-global таблица до 256 ID, пиксели выделяются через `malloc` | `картинка_освободить`; process-exit освобождает все занятые слоты | ID общие для VM; забытые ID удерживают память до выхода процесса |
| `mod_sound` | Process-global таблицы sounds/voices, один WinMM mixer thread | `звук_освободить`, `звук_остановить`; process-exit останавливает thread, закрывает waveOut и освобождает samples | Нет VM ownership; аппаратный путь не покрыт автоматическими тестами |
| `mod_window` | Process-global HWND, framebuffer, font cache и text queue | закрытие окна/выход pump; process-exit cleanup освобождает HWND, font cache, очередь текста и framebuffer | Один оконный контекст на процесс; GUI-сценарии требуют ручной проверки |
| `mod_gl` | Process-global WGL contexts и таблицы программ/буферов/текстур | явный `destroy`; process-exit вызывает общий cleanup | Один GL context на процесс; настоящий драйвер и несколько VM не проверены |
| `mod_d3d11` | Process-global D3D device/swapchain и таблицы COM resources | явный `destroy`; process-exit вызывает общий `Release`/cleanup | Один D3D device на процесс; реальный графический runtime не проверен |

## Безопасная область применения

Проверенный контракт для этих старых биндингов — одна последовательно
используемая runtime-сессия в одном процессе. Их ID и глобальное состояние нельзя
считать изолированными между несколькими VM. Новый `VAL_NATIVE_RESOURCE` и FFI
lease не заменяют эти старые таблицы. Process-exit cleanup закрывает системные
ресурсы при штатном завершении, но не освобождает их сразу при уничтожении
встроенной VM.

На Windows/MSVC прошли сборка, полный CTest и AddressSanitizer. `tests/resource_finally.c`
проверяет, что явное `ресурсы.закрыть` в `всегда` освобождает handle ровно один раз
даже когда исходная ошибка остаётся неперехваченной.
Эти автоматические тесты проверяют runtime/FFI/память, но не создают реальный
звук и не выполняют ручное окно/OpenGL/D3D rendering. Для 1.0 graphics/audio
модули остаются расширениями с ограничением «одна VM на процесс»; многопоточная
VM и GPU async lifetimes не поддерживаются.
