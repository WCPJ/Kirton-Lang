# Kirton: продолжение работы — Memory System V2.1

Дата: 2026-11-03. Исходная база: `kirton-memory-v2-preview.zip` (предыдущий
этап, 38 CTest).

## Что изменено

- `include/kirton/value.h`, `src/value.c`: добавлен `VAL_TYPED_ARRAY`,
  `KirTypedArray`, API выделения/чтения/записи массивов. Четыре скалярных
  представления, контролируемая арена, нулевое заполнение, защита границ,
  выравнивание и поколение арены. Массивы входят в GC-граф.
- `src/mod_memory.c`: язык получил функции `массив`, `длина_массива`,
  `тип_массива`, `действителен_массив`, `взять` и `положить`.
- `src/eval.c`: поддержка выражений `массив[индекс]`, присваивания и
  `для каждого ... в массив`, проверка на неверный срок жизни.
- `src/mod_runtime.c`, `src/mod_list.c`, `src/mod_json.c`: имя типа,
  сравнение по идентичности, запрет неявной JSON-сериализации массива.
- `src/value.c`: на границе C API проверка памяти чужой VM теперь
  рекурсивно обходит вложенные списки и словари, включая циклические.
- `CMakeLists.txt`, `tests/memory_v2_typed*`: новые скриптовые и C-тесты,
  включая нагрузочный тест 250 повторных арен на 1 млн `целое64`.
- `docs/MEMORY_V2_1.md`: описание API и текущих ограничений.

## Проверки

Окружение: Debian Linux, GCC 14.2.0, CMake 3.31.6.

| Проверка | Результат |
|---|---|
| CMake Release | Успешно |
| CTest Release | 45/45 |
| CMake Debug, ASan + UBSan + LSan | 45/45 |
| Сценарий: точное целое > 2^53 | Успешно |
| Границы 32- и 64-битных типов | Успешно |
| GC/VM isolation + pin/unpin | Успешно |
| 250 x 1 млн элементов/сброс/GC | Успешно |

Честное ограничение: прохождение тестов **не доказывает** отсутствие всех ошибок
управления памятью; тесты с `WILL_FAIL` проверяют завершение с ошибкой.
Windows/MSVC и многопоточный доступ не тестировались.

## Не сделано

Структуры с фиксированной раскладкой и ссылочные объекты в аренах, модель
заимствований, `unsafe`, C ABI, учёт *всей* памяти VM, обработка ошибок в
самом языке, конкурирующий GC и оптимизирующий компилятор. Следующая часть
должна начинаться со спецификации безопасных структур/владения, а не с
произвольных указателей.
